# Project Statement

## Project Title

Computer Vision Image Transformation Tool

## Problem Statement

Image transformation is an important concept in Computer Vision and Image Processing. Different transformations are required to modify image brightness, contrast, orientation, size, position, and geometric appearance.

The purpose of this project is to develop a command-line based image transformation tool that allows users to apply different image processing and geometric transformations to an input image.

## Scope

The project focuses on basic image enhancement, image processing, and geometric transformation techniques using Python, OpenCV, and NumPy.

The project provides 13 transformations:

- Brightness
- Contrast
- Negative
- Gamma Transformation
- Thresholding
- Translation
- Scaling
- Rotation
- Horizontal Reflection
- Vertical Reflection
- X-axis Shearing
- Y-axis Shearing
- Affine Transformation

## Target Users

The project can be used by:

- Students learning Computer Vision
- Beginners learning image processing
- Users who want to experiment with basic image transformations
- Students studying geometric transformations

## High-Level Features

1. Load an input image.
2. Select an image transformation through a command-line menu.
3. Apply the selected transformation.
4. Save the transformed image automatically.
5. Handle invalid input and missing image errors.
6. Provide automated tests for the transformation functions.
