# Computer Vision Image Transformation Tool

## Project Description

This project is a Python-based Computer Vision Image Transformation Tool developed using OpenCV and NumPy.

The tool allows users to apply different image enhancement, image processing, and geometric transformations to an input image through a command-line interface.

## Features

The project provides the following transformations:

- Brightness adjustment
- Contrast adjustment
- Negative transformation
- Gamma transformation
- Thresholding
- Translation
- Scaling
- Rotation
- Horizontal reflection
- Vertical reflection
- X-axis shearing
- Y-axis shearing
- Affine transformation

## Technologies Used

- Python 3
- OpenCV
- NumPy

## Requirements

- Python 3.x
- OpenCV
- NumPy
